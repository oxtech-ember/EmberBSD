# Native expr bootstrap

The normal host target uses `bin/expr/expr.y` and `tools/Makefile.host`.
It keeps the normal compatibility library and the source compiler flags.
The grammar uses the selected host yacc.

`bootstrap.json` defines a finite Darwin bootstrap route.
The SDK requires an accepted native GCC16 and an explicitly selected native yacc.
The current common Ports Byacc provider supplies that generator.
The runner creates `expr.c` in its private work directory.
It records the generated bytes and checks them before each later command.
No generated implementation is stored in this directory.

The 52 cases cover arithmetic, precedence, comparisons, short circuit evaluation,
basic regular expressions, captures, length, syntax failures, and arithmetic errors.
Expected bytes and statuses belong to this manifest.
The finite route uses the C locale and does not prove every multibyte locale.
Native execution, memory checks, and C analysis require separate evidence.

The canonical repair uses zero flags for POSIX basic regular expressions.
It releases a successfully compiled expression on both match outcomes.
It also checks `asprintf` return values before using their outputs.
It preserves allocation error details across regex cleanup.
The existing NetBSD notices remain intact. No donor implementation is copied.
The manual describes the existing character count and invalid-sequence fallback.
