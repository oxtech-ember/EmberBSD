# A133 PCM core validation

## Delivered scope

Portable production format and transfer-geometry functions for a future A133
codec driver. The core is not in kernel configuration and exposes no audio(4)
device. This milestone performs no playback, capture, GPIO or supply writes.
Both plan tasks are complete; the larger tablet/audio workflow remains open.

## Evidence

- Clean native source pin: `68ee276619b9ed78c7a271520c9b5386e5850786`.
- PCM contract passed on macOS/Clang and NetBSD 11/aarch64/GCC 12.5.
- macOS AddressSanitizer and UndefinedBehaviorSanitizer contract passed.
- Real configured `EMBER64_A133_EMMC` compiler flags, including `_KERNEL`,
  freestanding AArch64 and warnings as errors, compiled the same core.
  This is a kernel-context object build, not a complete driver/kernel build.
- Existing FDT, Ethernet pin, Goodix frame and reset contracts passed on both
  host and native build machine. The native FDT library was rebuilt from the
  matching NetBSD source tree for that contract.
- Independent GPT-6 Astra read-only review: zero critical or important findings.
  It checked all five plan review-focus cases and the primary manual FIFO
  fields. Two documentation issues were corrected: the canonical board catalog
  row and the ADC FIFO control section reference. The reviewer did not repeat
  native execution or physical-board acceptance.
- Core/test/check-script files match the native pin after the prose corrections.

The format test first failed because production source was absent. The ring
test then failed because its API was absent. Native kernel-context compilation
caught missing NULL definitions under `_KERNEL`; adding `sys/param.h` and
persisting that compiler gate fixed the regression. All gates passed afterward.

## Decisions and remaining boundaries

The operator authorized autonomous night work without questions or sound and
microphone tests. Work proceeded inline in an isolated branch from the verified
kernel #7 snapshot. The main checkout and its outstanding changes were preserved.
Fresh `origin/main` was checked; its newer overview remains to be reconciled
before publication. A narrow main fetch avoids remote branch-name case clashes
on case-insensitive filesystems; no repository ref-format migration was made.

The core returns format words with enable/IRQ/DRQ/flush bits cleared. Encoding
and precision validation belongs to the future audio_hw_if adapter. Completion
releases a copied memory span; it does not certify hardware consumption or
accurate presentation timing. Callers must serialize ring access.

No audio_hw_if, MMIO FIFO packing, clock/GPIO ownership, power control, IRQ/DMA
service, underrun/overrun recovery, physical duplex or speech quality is claimed.
These were considered by the reviewer and correctly remain follow-up work.
The amplifier's active polarity still needs an isolated daytime acoustic check;
the earlier audible low-PF6 probe alone is not that check. The source branch is
retained locally; it has not been pushed, merged or installed as a new kernel.
