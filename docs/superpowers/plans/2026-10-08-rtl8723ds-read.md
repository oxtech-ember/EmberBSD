# RTL8723DS Read Transport Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans inline. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Execute bounded, error-reporting native CMD52 reads on the inspected YS-M33 SDIO radio.

**Architecture:** A portable guarded read helper plus a synchronous diagnostic SDIO attachment; a separate kernel configuration selects it. Installed eMMC and other drivers are retained.

**Tech Stack:** KNF C, libfdt, NetBSD 11/aarch64 GCC 12.5, native SD/MMC API, volatile vendor U-Boot opt-ins.

**Spec:** ../specs/2026-10-08-rtl8723ds-read-design.md

## Global Constraints

- No physical playback/microphone recording, questions, PMIC/radio/CCCR writes or custom boot firmware.
- Function 1, manufacturer 0x024c, product 0xd723, interface 0x07; actual MMC1 FDT parent and both zero-length opt-ins required.
- Domain 0x10250000 maps local offset 0..0xfff; domain 0x10260000 maps 0x10000 | MAC offset 0..0xffff.
- CMD52 read only; reject domain crossing and card R5 errors; keep caller output unchanged on failure.
- Probe CCCR enable/ready, SYS_CFG1 0xf0, SYS_CFG2 0xfc, HCI suspend 0x86 and repeated SYS_CFG1; stop on first error.
- Diagnostic RAM boot only; restore ordinary installed audio kernel and unchanged boot wedge.

## Review Focus

- Actual parent devhandle type and FDT offset must gate the driver before I/O.
- Host-error and R5-error handling must never manufacture successful zero data.
- Shared SDIO command serialization/card selection and detach must remain safe.
- Missing/malformed opt-ins and disabled function must not trigger writes or unbounded retries.
- Native headers/config registration, kernel compile flags and imported license/provenance must match the portable test.

### Task 1: Guarded read helper and native diagnostic attachment

**Files:**
- Create `sys/dev/sdmmc/rtl8723ds_read.{c,h}`: domain conversion, read-only command/R5 handling and FDT/card guard.
- Create `sys/dev/sdmmc/rtl8723ds_probe.c`: native synchronous command callback and attachment.
- Modify `sys/dev/sdmmc/files.sdmmc`: optional diagnostic device/files.
- Create `sys/arch/evbarm/conf/EMBER64_A133_SDIO`: include AUDIO plus diagnostic.
- Create `ember/tools/rtl8723ds-read-test.{c,sh}`: production-source read/guard contract.

**Interfaces:**
- `bool rtl8723ds_read_match(const void *fdt, int host_offset, uint16_t vendor, uint16_t product, int function, int interface)`.
- `struct rtl8723ds_read_ops { int (*command)(void *, uint32_t, uint32_t *); void *cookie; }`.
- `int rtl8723ds_read8(const struct rtl8723ds_read_ops *, unsigned int function, uint32_t bus_address, uint8_t *)`.
- `int rtl8723ds_read32(const struct rtl8723ds_read_ops *, uint32_t logical_address, uint32_t *)`.
- Native callback consumes a read-only CMD52 argument and returns the full R5 response/error; caller ensures card selection in the SDIO attachment task.
