# Source inputs of the kernel contracts in kernel-contracts.sh.
# Each line is CONTRACT INPUT, or only CONTRACT. An INPUT that ends in /
# names the files directly in that directory. An INPUT that ends in /**
# names all files below that directory. Other INPUTs name one file.
# kernel-contracts-select.py runs a contract when one of its inputs or the
# contract itself changes. A contract without a line runs on each change.
# kernel-contracts-trace.py records the lines from the files that each
# portable contract reads. Run it again when a contract reads other files.
# The record does not see a file that a contract only looks for, and it does
# not see a recursive walk of a directory. Add such inputs by hand.
