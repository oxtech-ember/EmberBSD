## Hardware notes

Boots from SPI flash on a development board and runs multi-user programs in 16 MB:
the vendor SPL, OpenSBI and U-Boot start a stub that copies the kernel segments to
PSRAM. The port is `sys/arch/riscv/espressif` with the kernel configurations
`ESP32S31` and `ESP32S31W`: Sv32 with a direct map, CLIC interrupts through the
interrupt matrix, the system timer, the firmware console as a tty, the root file
system read from a flash range named in the device tree.

The kernel is built without floating point; with `MKSOFTFLOAT=yes` the riscv32
libraries are built for the `ilp32` ABI without F and D, and a program supplies the
arithmetic routines itself. Ethernet through the DesignWare GMAC with short rings.

Wi-Fi in `ESP32S31W`: the vendor's closed radio libraries are linked into the kernel
behind a shim that gives them the operating system services they expect, and the
`espwifi` interface joins a WPA2 network on 2.4 GHz; the network list comes from the
device tree. The libraries are not part of this tree. 6000 pings in 100 minutes
passed without a loss.

One of the two cores runs. Tested on physical hardware with a statically linked
application of about 2 MB that keeps a TLS connection to a server; radio power
saving, Bluetooth, 802.15.4, USB and the second core are not implemented
